# swiatowid-testy
Buildy prototypu do testów (bez kodu gry). Pobierasz z zakładki **Releases**.

## Zgłoszenia
- **Błąd:** [nowe zgłoszenie → Błąd](../../issues/new?template=blad.yml). Od wersji z klawiszem **F8** gra sama zapisze paczkę (zrzut, wersja, ostatnia minuta telemetrii) — przeciągnij ją do zgłoszenia.
- **Wrażenia po sesji:** [nowe zgłoszenie → Wrażenia po sesji](../../issues/new?template=wrazenia.yml) — ocena „zagrasz jeszcze raz?” 0–10 i co frustrowało. Po każdej sesji, nawet krótkiej.

Nie wpisuj danych osobowych. Telemetria nie zawiera danych osobowych (opis w `TELEMETRIA.txt` w paczce).
